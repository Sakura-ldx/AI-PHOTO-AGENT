# MVP 路线图

## Phase 0：项目基础

- 定义产品目标和范围。
- 选择初始应用架构。
- 定义内部编辑参数 schema。
- 定义 Lightroom 导出映射。
- 定义学习参考图的图像来源策略。

## Phase 1：自动编辑原型

- 构建图像上传流程。
- 提取图像元数据。
- 调用视觉模型进行图像诊断。
- 生成 3 个风格推荐。
- 将所选风格转换为内部编辑参数。
- 渲染本地预览。
- 导出 `.xmp` 预设文件。

## Phase 2：摄影学习原型

- 添加参考图像导入或允许来源搜索。
- 分析参考图像的构图和色彩。
- 按风格归类发现。
- 生成可复用的学习笔记。
- 在一个工作流中展示参考图、视觉分析和学习总结。

## Phase 3：产品集成

- 将编辑建议与学习示例连接起来。
- 让用户将上传照片与已分析的参考图进行比较。
- 保存用户会话和生成的预设。
- 如有需要，添加账户、历史和收藏概念。

## Phase 4：质量与扩展

- 提升 Lightroom 参数保真度。
- 添加更多图像格式和接近 RAW 的工作流。
- 添加批量编辑建议。
- 添加风格库。
- 添加更丰富的来源治理和署名能力。

## 第一批工程里程碑

1. 创建最小 Web 界面，支持上传、分析结果、风格选择、预览和预设导出。
2. 实现内部编辑参数 schema。
3. 实现 `.xmp` 导出生成。
4. 添加用于图像分析的模型适配器接口。
5. 添加摄影学习的参考图像摄入路径。
